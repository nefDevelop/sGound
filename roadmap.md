# sgound Roadmap

## Audio & Core
- [ ] **ReplayGain implementation:** Extract `REPLAYGAIN_TRACK_GAIN` from tags and apply volume normalization in the streaming engine (ffmpeg filter).
- [ ] **Multi-user detailed permissions:** Fine-tune read/write access per collection or folder.

## User Experience & Aesthetics
- [ ] **Cinema Mode:** A dedicated, ultra-minimalist playback view designed for large monitors or TV screens. Includes dynamic blurred backgrounds based on cover colors, elegant typography, and zero-distraction interface.
- [ ] **Artist Detail Panel:** Enhanced artist view that pulls real-time information from external APIs:
    - **Wikipedia:** Biographies and history.
    - **Fanart.tv / Last.fm:** High-resolution artist photography and logos.
- [ ] **Custom Smart Playlists:** Advanced rule builder to combine multiple criteria (Genre, Rating, Date, Bitrate, etc.).

## Mobile & Integration
- [ ] **Full OpenSubsonic compliance:** Ensure 100% compatibility with advanced clients like Symfonium and Strawberry.
- [ ] **Offline Mode (PWA):** Improved caching for mobile browser usage.
